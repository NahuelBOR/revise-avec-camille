# Révise avec Camille — Apprenons le français 🇫🇷

Application web interactive pour apprendre et réviser le français à travers des jeux ludiques et dynamiques.

## 🎮 Matières et Jeux inclus

- 📚 **Vocabulaire**
  - **🃏 Flashcards** : Cartes interactives façon poker (français ↔ espagnol) avec gestion de deck et audio.
  - **🧠 Quiz Vocabulaire** : Quiz à choix multiples basé sur des images et objets de la vie réelle.
- 🗣️ **Prononciation**
  - **➕ La règle du PLUS** : Entraînement interactif pour maîtriser la prononciation du mot *PLUS* ([PLY], [PLYS] ou liaison [PLYZ]) avec tableau de rappel et explications détaillées.
- *(À venir)* : Verbes, Grammaire, Expressions, Compréhension écrite, Compréhension orale.

## 🛠️ Stack technique

- **React 19**
- **Vite**
- **Framer Motion** (animations & transitions fluides)
- **SpeechSynthesis API** (audio natif en français)

## 🚀 Installation et lancement

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Construire pour la production
npm run build
```
